## Design systems as implementation contracts

Figma supports collaborative design and governance. Resolved decisions are delivered through semantic tokens, components, explicit states, documented behavior, and versioned Storybook contracts that Engineering builds from.

The purpose is not just visual consistency. It is to make implementation decisions explicit and reusable, including the constraints that AI-assisted work must respect.

## AI autonomy: where to stop

My AI Automation Maturity Framework distinguishes three levels:

| Tier | What it means | Status on Strata |
|---|---|---|
| L1 — Workflow automation | Fixed rules, no reasoning | Shipped |
| L2 — Agentic integration | Agents interpret context and make bounded decisions within a workflow step | Shipped to production |
| L3 — Adaptive agent loops | Agents evaluate options against context, SLA data, and permission scopes | Designed and deliberately held back; never deployed or active, pending safe audit trails and permission scopes |

Greater autonomy is not automatically a better outcome. Human review remains where the operational risk requires it.
